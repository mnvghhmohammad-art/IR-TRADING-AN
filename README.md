## 📱 گرفتن فایل APK از گیت‌هاب (ساده‌ترین راه — بدون نصب هیچ‌چیز!)

1. یک اکانت [GitHub](https://github.com) بساز (اگر نداری).
2. روی گیت‌هاب یک **Repository جدید** بساز (مثلاً `IR-TRADING-AN`) — نوع Public یا Private فرقی نمی‌کند.
3. **کل محتویات این پوشه را** (نه پوشه‌ی والد، خود فایل‌ها را) آپلود کن. دو راه:
   - از سایت گیت‌هاب: دکمه `uploading an existing file` → همه فایل‌ها را بکش و رها کن → `Commit changes`
   - یا با دستورات:
     ```bash
     git init
     git add .
     git commit -m "IR.TRADIng.AN v1.0"
     git branch -M main
     git remote add origin https://github.com/USERNAME/IR-TRADING-AN.git
     git push -u origin main
     ```
4. در گیت‌هاب برو به تب **Actions** → روی **Build Android APK** کلیک کن → دکمه **Run workflow** → صبر کن (~۱۰ تا ۱۵ دقیقه).
5. بعد از سبز شدن ✅، روی همان ران کلیک کن → پایین صفحه بخش **Artifacts** → فایل **IR-TRADING-AN-apk** را دانلود کن.
6. فایل زیپ دانلودشده را باز کن؛ داخلش `app-release.apk` است → به گوشی بفرست → نصب کن
   (در تنظیمات گوشی اجازه «نصب از منابع ناشناس» را برای مرورگر/تلگرام فعال کن).

> 💡 هر بار که کد را push کنی، خودکار APK جدید ساخته می‌شود.

## 🔑 گرفتن کلید API صرافی‌ها

### نوبیتکس (پشتیبانی کامل)
1. وارد سایت نوبیتکس شو → **پروفایل** → **تنظیمات** → **API**
2. یک کلید جدید بساز؛ فقط دسترسی **«معامله»** را فعال کن (دسترسی «برداشت» را خاموش بگذار تا امنیت حساب حفظ شود)
3. کلید را کپی کن → در اپ: تب **صرافی‌ها** → **نوبیتکس** → کلید را وارد کن → **ذخیره** → **تست اتصال**

### بیت‌پین
1. سایت بیت‌پین → **پروفایل** → **API Keys** → کلید جدید بساز
2. در اپ وارد کن و تست بزن (معاملات بیت‌پین در حالت آزمایشی است؛ اگر API تغییر کرد از صفحه گیت‌هاب Issue بزن)

> 🔒 **امنیت:** کلیدها با `expo-secure-store` فقط روی خود گوشی (Keychain/Keystore رمزنگاری‌شده) ذخیره می‌شوند و به هیچ سروری ارسال نمی‌شوند.

## 💰 راه‌اندازی برداشت خودکار ۴۰٪ سود

1. تب **کیف پول** → شماره کارت و شبا را وارد کن → **ذخیره**
2. تب **ربات** → بخش «واریز سود به کارت» → **برداشت خودکار سود** را روشن کن
3. درصد (۴۰) و حداقل سود برای برداشت را تنظیم کن
4. حالا هر معامله سودده به‌صورت خودکار درخواست واریز آن درصد از سود را ثبت می‌کند
   ⚠️ اگر صرافی برای برداشت رمز OTP بخواهد (نوبیتکس همین‌طور است)، نوتیفیکیشن می‌گیری تا در اپ صرافی تایید کنی.

## 🏦 درگاه پرداخت زرین‌پال

1. در [zarinpal.com](https://zarinpal.com) پنل بساز و **مرچنت‌کد** بگیر
2. تنظیمات → «مرچنت‌کد زرین‌پال» → کد را وارد و ذخیره کن
3. سوییچ «درگاه پرداخت» را روشن کن — از این به بعد در تب کیف پول می‌توانی واریز کنی
4. بعد از پرداخت، دکمه **«بررسی وضعیت پرداخت»** را بزن تا واریز تایید شود

## 🖥 اجرای ربات ۲۴/۷ روی سرور (اختیاری ولی پیشنهاد می‌شود)

پوشه `bot-server/` یک ربات Node.js بدون هیچ وابستگی است که همان منطق اپ را اجرا می‌کند:

**روش سریع (رایگان):** [Render.com](https://render.com) → New Background Worker → ریپوی گیت‌هابت را وصل کن → دستور اجرا:
```bash
cd bot-server && cp config.example.json config.json
# فایل config.json را ویرایش کن و کلید API را بگذار، mode را "real" کن
node index.js
```

**روش VPS:** هر سرور اوبونتو:
```bash
cd bot-server
cp config.example.json config.json
nano config.json   # کلید API + mode: "real"
node index.js      # یا با pm2: pm2 start index.js --name irtan-bot
```

اعلان تلگرام (اختیاری): دو متغیر محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را ست کن.

## 🧠 ربات چطور تصمیم می‌گیرد؟

| سیگنال | منطق |
|---|---|
| روند | EMA9 بالای/پایین EMA21 |
| مومنتوم | MACD Histogram صعودی/نزولی |
| اشباع خرید/فروش | RSI(14) < 35 یا > 68 |
| بازگشت از کف/سقف | باند پایین/بالای بولینگر |
| حمایت/مقاومت | سقف و کف ۴۰ کندل اخیر |
| الگوها | انگلفینگ صعودی/نزولی، همر، دوجی |
| تاییدیه | حجم بالاتر از میانگین |

با هر سیگنال خرید: ورود + تعیین خودکار حد ضرر (۲٪) و هدف سود (۴٪) بسته به پروفایل ریسک.
پروفایل‌ها: **محافظه‌کار** (فقط روند صعودی، ورود کم)، **متعادل**، **تهاجمی** (ورودهای بیشتر).

## ⚠️ هشدار ریسک (مهم)

- این اپ **ابزار معاملاتی** است، نه مشاور مالی. هیچ سودی تضمین نمی‌شود.
- در حالت **«واقعی»**، سفارش‌ها با پول واقعی حساب صرافی تو ثبت می‌شوند — قبلش با حالت **«شبیه‌سازی»** تست کن.
- بازار رمزارز بسیار پرنوسان است؛ سقف ضرر روزانه و حد ضرر را جدی بگیر.
- برداشت خودکار به کارت به پشتیبانی API برداشت صرافی وابسته است؛ اگر صرافی OTP بخواهد، اپ به تو نوتیف می‌دهد تا دستی تایید کنی.
- API صرافی‌ها ممکن است تغییر کند؛ آداپترها طوری نوشته شده‌اند که خطا را محترمانه گزارش می‌کنند، به‌جای کرش کردن.
